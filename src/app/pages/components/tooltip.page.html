The bubble adds what the label cannot fit: a consequence, a shortcut, a timestamp. The tooltip as the only name Take the tooltip away — on touch, it already is — and the button is anonymous. Anything interactive, or anything the user must read slowly, belongs in a popover. Dismissible Escape closes the bubble — and only the bubble. The key never travels on to close the dialog the trigger happens to live in. Hoverable Moving the pointer onto the bubble keeps it open, so its text can be read at any zoom level without a race. Persistent It stays until hover or focus leaves. No timer takes it away mid-sentence. <ds-tooltip> Text only, on hover and focus, gone when they leave. Nothing inside it can be clicked, copied or tabbed to — if it could, the bubble would be a trap. <ds-popover> Opens on click, holds real content — forms, buttons, links — and stays until it is dismissed. Focus moves in, and Escape brings it back.
